# Визитка Андрея Малышева

Простая одностраничная сайт-визитка: фото, имя, род занятий и кнопка «Написать мне», которая открывает чат в Telegram ([@andmalyshev](https://t.me/andmalyshev)).

## Что внутри

- `index.html` — вся страница: разметка и стили в одном файле, без библиотек и сборки.
- `photo.jpg` — фото для аватарки.

Страница подстраивается под ширину экрана телефона и под тёмную тему системы.

## Как открыть

Скачайте репозиторий и откройте `index.html` двойным щелчком или из терминала:

```bash
open index.html
```

## Как изменить

- **Имя и род занятий** — строки `<h1>` и `<p class="role">` в `index.html`.
- **Фото** — замените `photo.jpg` (формат JPEG). Положение лица в круге задают свойства `width`, `left` и `top` в правиле `.avatar img`.
- **Ссылка кнопки** — атрибут `href` у кнопки `Написать мне`.
